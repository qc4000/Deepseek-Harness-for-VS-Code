## 1. 背景与问题

DSH Web GUI 是三栏布局：左侧栏（展开 264–420px，折叠为 56px 导轨）+ 对话区 +（可选）右侧栏；
视口 < 1024px 时 DSH 自动把左侧栏折叠成导轨。VS Code 的侧边栏视图通常只有 300–400px 宽，
这块导轨/侧栏直接吃掉 15%–60% 的可用宽度；编辑器标签页里则是 264–420px。

父容器（webview）与 DSH 页面**跨源**，无法直接改 DSH 的 DOM；按宪法第一条也不应注入脚本。
用户希望：**在侧边栏/面板等窄容器里默认隐藏它，并在插件顶部提供一个开关随时显示/隐藏**。

## 2. 目标

- 隐藏时只显示 DSH 的对话区，对话区占满整个面板宽度；显示时行为与 1.0.1 之前完全一致。
- 顶部固定 28px 工具条内提供切换按钮，状态清晰、可点击、可键盘操作、有 tooltip。
- 隐藏状态**可持久**（窗口重载后保持），且随时可被配置或按钮覆盖。
- 用户多次拖动 DSH 侧栏宽度（264–420）、折叠/展开（56）、改变面板宽度后，隐藏仍然精确（不留缝、不切到对话内容）。
- 切换**不重载 iframe**：DSH 的滚动位置、运行中的任务、输入框内容都不受影响。
- 不改 DSH 页面内容或事件（只做父容器视口裁剪）；能力可完全关闭。

## 3. 非目标

- 不新增 VS Code 底部面板容器（用户可自行把视图拖到 Panel；新增容器涉及"单活动视图"重构，另立项）。
- 不隐藏 DSH 右侧栏（rightbar），不改 DSH 内部布局状态（不调用 `ctx.layout.toggleSidebar()`）。
- 不提供"新会话"按钮；隐藏期间新建/切换会话需先点显示。
- 不修复 DSH 在窄容器下的其它响应式行为。

## 4. 用户故事

- 作为 **VS Code 用户**，我希望在窄面板里把 DSH 的左侧栏收起来，以便对话区更宽、少滚动。
- 作为 **DSH 二次开发者**，我希望这个接管完全不碰我的页面，并且能一键关掉，以便我的定制不受影响。

## 5. 验收标准

- **AC-1（窄容器默认隐藏）**：Given `dshPanel.dshSidebar=auto`（默认）且面板宽度 < 1024px，When 打开面板，
  Then DSH 左侧栏不可见、对话区占满宽度；Given 宽度 ≥ 1024px，Then 左侧栏保持可见。
- **AC-2（按钮切换）**：Given 面板已加载，When 点击顶部工具条按钮，Then 立即隐藏/显示 DSH 左侧栏，
  iframe 不重载（DSH 滚动位置与输入框内容保留），按钮 tooltip/`aria-label` 随状态切换。
- **AC-3（宽度自适应）**：Given 已隐藏，When 用户在 DSH 内把侧栏从 280 拖到 264/420、或折叠/展开，
  Then 隐藏仍然精确（不露出侧栏、不裁掉对话内容）；Given 面板宽度改变，Then 同上。
- **AC-4（持久化与优先级）**：Given 用户手动隐藏，When 重载窗口或切换视图，Then 仍隐藏；
  Given 之后把 `dshPanel.dshSidebar` 改为 `show`/`hide`，Then 配置生效并清除手动覆盖。
- **AC-5（配置完全关闭）**：Given `dshPanel.dshSidebar=show` 且用户未手动切换，Then 不安装/不更新测量插件、
  不裁剪、不显示按钮以外的任何干预，行为与 1.0.1 之前一致。
- **AC-6（测量不可用不静默）**：Given 测量插件缺失或未能握手，When 触发隐藏，Then 不做裁剪
  （保持原样）并在状态栏给出一次中文提示说明原因与出路。
- **AC-7（拖动手柄不泄漏）**：Given 侧栏处于展开态且已隐藏，Then 可见区最左侧不会出现 DSH 的
  8px 拖动手柄热区（点击对话区左缘不会误改侧栏宽度）。
- **AC-8（平台与缩放）**：Given `editor.fontSize` 为 12/16/20 三档（缩放 0.75/1/1.25），
  Then 裁剪量与缩放无关（不出现错位/白边/内容被切）。

## 7. 约束（引用宪法）

- 第一条：只做**父容器视口裁剪**（改外层 stage/clip 尺寸与偏移），不注入脚本、不改 DSH DOM/事件；
  能力可被配置关闭。已在宪法第一条补充该边界说明。
- 第三条：测量不可用、插件未生效必须可见提示；不得静默"点了没反应"。
- 第四条：不得让 1.0.0 的既有行为变差；`show` 时零干预；新旧 dsh 都要有确定行为。
- 第五条：新增消息字段做类型与长度校验（宽度为有限数、0–1024 之间，超范围丢弃）；
  不新增权限、不落盘敏感信息。
- 第六条：裁剪数学与策略判定必须可离线测试。
- 第七条：新增配置项同步 README 配置表；行为变更写 CHANGELOG。

## 8. 失败与提示

| 失败场景 | 用户可见提示 | 出口动作 |
| --- | --- | --- |
| 测量插件缺失/未握手 | 状态栏「DSH 侧栏宽度不可用，本次未隐藏（配套插件未生效）」 | 提示重启 dsh web / 检查 `workspaceFileLinkAction` 类开关 |
| 测量值异常（非有限数/超范围） | 丢弃该值，保持当前裁剪量 | 下次测量自动纠正 |
| 插件刚安装/升级 | 信息「已自动安装/更新 DSH 插件（…），请点击面板顶部的「重启 dsh web」使其生效」 | 用户重启 |
| 配置为 `show` | 无提示（正常关闭态） | 用户可随时手动切换 |

## 9. 风险与已知限制

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| DSH 内部类名/布局规则变更（`_sidebarCol`、264/420/56/1024） | 测量失效或裁剪错位 | 按局部 token 匹配 + 读不到即不裁剪 + 提示；DSH 升级需回归（写入 ARCHITECTURE 已知限制） |
| 隐藏使 DSH 视口变宽（`V + crop`），968–1024 区间会跨过 DSH 的 1024 断点 | 侧栏由 56 变 280（被裁掉，用户不可见），可能有一次跳变 | 用"上次测量值 + 断点预测"先给目标裁剪量，实测再校正；写入已知限制 |
| 折叠动画 300ms 与裁剪不同步 | 短暂露出 | 收到 `animating` 时延迟到动画结束再取值；裁剪本身加 0.3s 同缓动过渡 |
| 28px 工具条 | 永久少 28px 高度 | 用户可把 `dshPanel.dshSidebar=show` 关闭功能；后续可选"悬停浮现"形态 |
| 被裁区域内的键盘焦点 | 焦点环不可见 | 已知限制，记录在案 |
