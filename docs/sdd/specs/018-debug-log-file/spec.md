## 1. 背景与问题

016 的侧栏诊断只写到**输出面板**：用户重启窗口后就没了，跨会话排障拿不到时间线；而「偶发闪烁/闪一下」
这类问题往往要前后对比。用户要求：把调试日志写到文件，并给一个默认关闭的设置项，方便以后排查。

## 2. 目标

- 新增配置 `dshPanel.debugLogToFile`（boolean，**默认 false**）。开启后把调试日志追加到
  `<用户主目录>/.dsh-debug/dsh-vscode-debug.log`（与模型诊断同目录），超过 2MB 自动轮转为 `.log.1`（只留一份）。
- 落盘内容：侧栏诊断包（页面侧 + 面板侧时间线，含 `ratio/rect/clip`、`ovr/skipped` 等排障字段）、
  手动显示/隐藏、`dshPanel.dshSidebar` 策略变更、插件安装变化、扩展激活（版本）。
- 新增命令「DeepSeek Harness: 打开调试日志」；文件未生成时给出开启指引（不静默）。
- 安全与稳健：落盘前统一脱敏（`token=…` → `token=***`），只写布局数值与短枚举；任何 IO 失败只提示一次，
  绝不影响面板功能；日志路径在工作区外（用户主目录），不污染仓库。

## 3. 非目标

- 不记录对话内容、文件内容、路径、Cookie、令牌。
- 不做日志级别（全部是调试事件）；不写 workspace 内（避免被提交/打包）。
- 不替换 016 的输出面板（面板仍立即可见、可一键复制）。

## 4. 用户故事

- 作为 **VS Code 用户**，我希望在设置里打开一个开关后，问题现场能留到文件里，重启后还能交给维护者。
- 作为 **维护者**，我希望拿到的是带时间戳的两侧时间线（而不是用户口述），且里面不会出现 token。

## 5. 验收标准（必须可执行）

- **AC-1（默认关闭）**：Given 未设置 `dshPanel.debugLogToFile`，When 产生诊断包，Then 不创建日志文件、
  `debugLogEnabled()` 为 false；且 `package.json` 中该配置项 `type=boolean, default=false`。
- **AC-2（开启后落盘）**：Given 配置为 true，When 收到 `dsh-sidebar-diag`，Then 文件存在且含
  `[sidebar-diag]`、诊断原因与两侧条目；首次写入在状态栏提示一次并带**文件路径**。
- **AC-3（脱敏）**：Given 诊断条目里含 `?token=SECRET`，When 落盘，Then 文件里不出现 `SECRET`，
  出现 `token=***`。
- **AC-4（轮转）**：Given 单条日志使文件超过 2MB，When 写入，Then 旧内容改名 `.log.1`（覆盖旧备份）、
  当前文件继续可写。
- **AC-5（命令）**：When 执行「打开调试日志」，Then 文件存在时用编辑器打开；不存在时给出
  「尚未生成 + 去设置里开启」的指引（不静默）。
- **AC-6（失败不打断）**：Given 日志目录不可建（同路径已存在普通文件），When 写日志与收到诊断，
  Then 状态栏提示一次「调试日志写入失败…」，输出面板照常写入，功能不中断。

## 6. 兼容矩阵

| 场景 | 行为 | 说明 |
| --- | --- | --- |
| 默认（未开启） | 不落盘 | 与 016 完全一致 |
| 开启 | 输出面板 + 文件双写 | 文本同一份 |
| 主目录不可写 / 磁盘满 | 提示一次，功能继续 | 不影响裁剪与转调 |
| 旧版本记录的文件 | 不读取、不迁移 | 仅追加 |
| 打包 | 日志在用户主目录，不进 `.vsix` | `.dsh-debug/**` 已被忽略 |

## 7. 约束（引用宪法）

- 第二条：只用 Node 内置 `fs`/`os`/`path`，零依赖零构建。
- 第三条：开启、失败、文件缺失都有可见提示与出口。
- 第五条：落盘前统一脱敏；只写布局数值/短枚举；不新增权限。
- 第六条：AC-1..AC-6 全部可在 `test/dsh-sidebar.test.js` 离线断言（HOME 指向临时目录）。

## 8. 失败与提示

| 失败场景 | 用户可见提示 | 出口动作 |
| --- | --- | --- |
| 目录/文件不可写 | 状态栏一次「调试日志写入失败：无法创建 &lt;路径&gt;（请检查目录权限，或在设置里关闭 dshPanel.debugLogToFile）」 | 修权限或关开关 |
| 命令执行时无文件 | 信息提示「调试日志尚未生成：请在设置里打开…」+ 路径 | 打开设置 |
| 打开文件失败 | 错误提示带路径 | 手动打开该路径 |

## 9. 风险与开放问题

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 长时间开启导致文件增长 | 占磁盘 | 2MB 轮转 + 只留一份（上限约 4MB） |
| 同步写日志阻塞扩展宿主 | 极端磁盘慢时卡顿 | 每次仅一行追加；失败即降级并提示 |
| 用户误把 token 写进别的日志调用点 | 泄露 | 统一走 `debugLog` + `scrubDebugText`；新调用点只传数值/枚举 |
